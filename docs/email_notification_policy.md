# Email Notification Policy

## 🎯 현재 기준

- ✅ 정말 중요한 상태 변경은 즉시 이메일
- 🔔 나머지는 인앱 알림 우선
- ⏸️ cron이 필요한 지연/묶음 메일은 현재 보류
- 🌐 새 guest/host 즉시 메일은 `preferred_locale` 기준으로 발송, admin/team 수신 메일은 한국어 유지

---

## 📌 현재 운영 정책

### 관리자 알림센터

- ✅ `notifications` 테이블 재사용
- ✅ Admin Dashboard `ALERTS` 탭에서 운영 알림 누적 확인
- ✅ 팀스페이스, 서비스 운영 이벤트, 호스트 신청, 체험 신청, 일반 예약/결제/취소, 맞춤 의뢰 생성 등을 메일과 별도로 인앱에서 추적

### 즉시 이메일

- 🏦 일반 예약 무통장 입금 대기 관리자 알림
- 💳 예약 결제 완료
- ❌ 예약 취소 완료
- 🛠️ 호스트 신청 결과
  - 승인
  - 보완 요청
  - 거절
- 📥 무통장 입금 확인 완료
- ☎️ 전화 예약 신규 접수 관리자 알림
- ☎️ 전화 예약 결제 확인 / 취소 / 환불
- 📞 전화 예약 운영 답글
- 💬 문의 새 메시지
- ⭐ 새 후기 등록
- 📩 서비스 새 지원자 등록
- 🎉 서비스 호스트 선택 완료
- 💰 서비스 결제 완료
- 🛑 서비스 취소 요청 / 취소
- ✅ 팀 할 일
- ✅ 팀 할 일 댓글
- 👥 팀 메모 / 메모 답글

### 인앱만

- ✍️ 후기 작성 요청
- 🧭 서비스 매칭 일반 상태 변경
  - 다른 호스트 선택됨

---

## 🚨 보류된 정책

아래 방향은 맞지만, 지금은 적용하지 않는다.

- 💬 문의 `미읽음 10분 후 1회 메일`

보류 이유:

- GitHub Free 비공개 저장소의 Actions minutes 한도와 맞지 않음
- 별도 스케줄러 없이 운영하면 비용 대비 효율이 낮음

현재 예외:

- ✅ 팀 할 일은 즉시 메일 발송
- ✅ 팀 할 일 댓글은 즉시 메일 발송
- ✅ 고객센터 1:1 문의(`admin_support/admin`)는 `미읽음 10분 후 1회` 관리자 메일 + `ALERTS` 적재
